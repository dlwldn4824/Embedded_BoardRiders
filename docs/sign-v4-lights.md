# 신호등: 아래쪽(빨강 등)만 보일 때 꺼짐/켜짐 구분 (2026-11-10)

## 문제
정지선 근처에서 카메라에 신호등 위쪽(초록 등)이 안 보이고 빨강 등만 보이면, 꺼진 빨강을 켜진 빨강으로 볼 수 있다.

## 시도: v4 학습 (`sign/make_v4.py`)
- 기존 신호등 사진에서 신호등 상자의 위쪽 45~60% 를 잘라 낸 사진 652장을 더했다.
  - 초록 신호를 자르면 꺼진 빨강만 보인다 → green_light
  - 빨강 신호를 자르면 켜진 빨강만 보인다 → red_light
- 실제 신호등 사진 5장(자른 버전 포함 11장)도 넣었다 (`data/raw/lights_20261110`, 로컬 전용).
- v3 26n 가중치에서 320 으로 30 epoch 이어서 학습했다 (`runs/sign/v4_26n_320`).

## 결과 (아래쪽만 자른 신호등 val, conf 0.5)

| 모델 | 꺼진 빨강 29개 | 켜진 빨강 38개 |
|---|---|---|
| v3 26n (PyTorch, 320) | green 28, 못 봄 1, red 로 오인 0 | red 37, 못 봄 1 |
| v4 26n (PyTorch, 320) | green 26, 못 봄 3, 오인 0 | red 36, 못 봄 2 |
| Pi 모델 v3 26n INT8 320 | green 7, 못 봄 22, 오인 0 | red 38 |

- 전체 val mAP50: v4 0.963 (v3 320: 0.977). crosswalk 0.903 (v3 0.934).
- v3 원본은 이미 잘 구분한다. 차이는 INT8 변환에서 생긴다. v4 는 나아지지 않아 쓰지 않는다.
- 실차에서도 신호등 인식은 잘 되고 있어 Pi 모델은 그대로 둔다.

## 정지 위치
빨간불을 너무 멀리서 보고 멈췄던 문제는 성호 PR #1 ("규칙 추가")에서 고쳤다.
- 빨간불은 기억만 하고, 차 바로 앞 횡단보도(CROSSWALK 이벤트: 상자 아랫변 y ≥ `min_y2`, 화면 가운데를 덮음)가 오면 그 앞에서 선다.
- 이후 "횡단보도 쪽으로 살짝 더 붙기"로 `SIGN_CLASS_RULES["crosswalk"]["min_y2"]` 를 350 → 365 로 올렸다.
  - 350 일 때 확정까지 약 3cm 더 가서 y2 390 근처에서 섰다.
  - 395 이상은 차체에 가려 영영 안 넘을 수 있다.

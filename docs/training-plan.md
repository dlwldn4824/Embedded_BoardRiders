# 모델 학습 방향

과목 이름이 "AI 시스템 최적화"인 만큼, 모델을 하나 만들고 끝내지 않고 **경량화 단계마다 전/후 수치**(크기, 지연, 정확도)를 남기는 것을 목표로 한다.

## 1. 시스템 구성

```
Pi Camera ──┬─► [Lane] 전처리 → Student CNN (INT8) → steer ∈ [-1, 1] ─┐
            │                                                       ├─► FSM ─► 후처리(LPF, 곡률 감속) ─► PWM
            └─► [Sign] YOLOv8n (INT8, 별도 스레드) ────────────────────┘
```

- **차선:** 조향각 회귀 CNN(PilotNet 기반) → 지식 증류(KD) → Pruning → PTQ INT8.
  - 지금은 팀 규칙 기반 주행 코드(`drive/`)로 달린다. CNN 은 이 주행 기록을 라벨로 학습한다.
- **표지판:** YOLOv8n INT8. 동작은 FSM 규칙으로 처리한다. 모델에게 동작까지 학습시키지 않는다.

## 2. 데이터

자세한 점검 결과는 [data-report.md](data-report.md).

### 2.1 차선 라벨
- 회귀에는 연속 조향값이 필요하다.
- 규칙 기반 주행을 `--record` 로 돌리면, 프레임 번호(`fid`)와 그때의 조향값이 CSV 에 같이 남는다. 이것을 라벨로 쓴다.
- 키보드식 이산 각도(45/90/135)만 있으면 시간 축으로 스무딩해 연속값으로 만든다.

### 2.2 수집
- 트랙 정방향/역방향, 바깥/안쪽 차선 모두.
- **복구 장면:** 일부러 차선 가장자리로 갔다가 돌아오는 장면을 전체의 15~20% 정도 넣는다.
- 조명 조건 3가지 이상. 배터리 잔량이 다를 때(속도가 달라짐)도 수집한다.
- 실제 주행할 Pi 카메라로만 수집한다.

### 2.3 분할과 증강
- **주행 세션(run) 단위로 train/val/test 를 나눈다.** 이웃 프레임이 섞이면 점수가 부풀려진다.
- 직진 프레임이 대부분이라 조향 크기 구간별로 가중 샘플링한다.
- 차선 모델 증강: 밝기/대비/HSV, 그림자, 작은 평행이동(+조향 보정), 모션 블러, 좌우 반전 + 조향 부호 반전.
- 표지판 모델에서는 좌우 반전을 쓰지 않는다 (left/right 가 뒤바뀜).

## 3. 차선 모델

### 3.1 입력 비교
| 후보 | 내용 |
|---|---|
| A | 하단 ROI 크롭 → YUV, 66×200 (PilotNet 입력) |
| B | A + LAB 채널 하나를 4번째 채널로 추가 |
| C | 초록 경계 이진 마스크만, 66×200×1 |

A 를 기준선으로 두고 B, C 와 비교한다.

### 3.2 Teacher
- PilotNet (Conv 5층 + FC), BatchNorm, Dropout 0.3, 출력 `tanh`.
- Loss: Huber, Adam lr 1e-3 + cosine, early stopping (val MAE 기준).

### 3.3 압축 파이프라인
| 단계 | 방법 | 합격 기준 (Teacher 대비) |
|---|---|---|
| ① KD | 채널을 절반 정도로 줄인 Student. `L = α·Huber(y, ŷ_s) + (1-α)·MSE(ŷ_t, ŷ_s)` | R² 하락 ≤ 0.01 |
| ② Pruning | magnitude pruning, sparsity 0 → 50% | R² 하락 ≤ 0.01 |
| ③ Fine-tuning | lr 1e-4, mask 고정 | 손실 회복 |
| ④ PTQ INT8 | TFLite full-integer, representative 300장 | 크기 < 200KB |

- 비구조적 pruning 은 TFLite 에서 속도를 거의 올리지 못하고 크기만 줄인다. 속도까지 얻으려면 채널 단위 pruning 을 하거나 KD 에서 채널 수를 줄인다.
- PTQ 손실이 크면 QAT 와 비교한다.

### 3.4 평가
- 오프라인: MAE, R², 커브 구간만 따로 계산한 MAE.
- Pi: 단계별 지연(ms), 크기(KB), CPU 사용률, 온도.
- 실주행: 완주율, 랩 타임, 차선 이탈 횟수. 오프라인 점수가 좋아도 실주행이 나쁘면 탈락이다.

## 4. 표지판 모델

- YOLOv8n, 10 클래스: `crosswalk, green_light, horn, left, red_light, red_line, right, speed_20, stop, straight`.
- 라벨링 규칙: 기둥 제외, 기호 전체 포함, 너무 먼 횡단보도는 라벨하지 않음, 한 이미지의 모든 객체를 라벨.
- 증강: `fliplr=0`, mosaic, HSV.
- 배포: TFLite INT8. 결과는 [sign-v2-int8.md](sign-v2-int8.md).
- 후처리: 같은 클래스가 15프레임 안에 2번 이상 검출될 때만 이벤트를 낸다. 클래스별로 박스 크기 · 위치 조건을 둔다.
